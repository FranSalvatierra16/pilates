# 💬 Mensaje para Explicar el Sistema - FitGest

## Versión Completa (para DM/WhatsApp)

```
¡Hola! Gracias por tu interés en FitGest 😊

Te cuento un poco del sistema:

FitGest es una plataforma completa de gestión diseñada específicamente para estudios de Pilates, Yoga y Funcional. Todo funciona desde tu celular, tablet o computadora, y todos los datos se guardan en la nube.

📋 FUNCIONES PRINCIPALES:

1️⃣ GESTIÓN DE ALUMNOS
- Registro completo: nombre, apellido, DNI, teléfono, email
- Fecha de vencimiento de cuota (se actualiza automáticamente al pagar)
- Actividad que realiza (para saber cuánto paga)
- Fecha de registro automática
- Búsqueda rápida por nombre o DNI

2️⃣ CONTROL DE ACCESO
- El alumno ingresa su DNI
- El sistema muestra automáticamente:
  🟢 Verde = Cuota al día (acceso permitido)
  🟡 Amarillo = Vence hoy (acceso permitido con aviso)
  🔴 Rojo = Cuota vencida (acceso denegado)
- Registra cada ingreso automáticamente
- Contador de clases asistidas

3️⃣ CALENDARIO DE CLASES
- Vista semanal con todos los turnos
- Horarios: 7:30-12:30 (mañana) y 16:00-21:00 (tarde)
- Asignás alumnos a cada clase
- Podés agregar título a cada clase
- Asignás profesores a cada turno
- Control de asistencia (✓ asistió, ✗ no asistió)
- Movés alumnos entre turnos fácilmente
- Estadísticas de asistencia por alumno

4️⃣ GESTIÓN DE PAGOS
- Registro de pagos (efectivo o transferencia)
- Al registrar un pago, la fecha de vencimiento se actualiza automáticamente (1 mes adelante)
- Historial completo de todos los pagos
- Podés editar la fecha de vencimiento si querés
- El contador de clases se reinicia al pagar

5️⃣ CAJA Y GASTOS
- Saldo de caja en tiempo real (Ingresos - Gastos)
- Totales separados: efectivo y transferencia
- Registro de gastos (también en efectivo o transferencia)
- Los gastos se descuentan automáticamente
- Estadísticas del día y del mes
- Promedio por pago
- Últimos pagos y gastos registrados

6️⃣ GESTIÓN DE ACTIVIDADES
- Creás las actividades que ofrecés (ej: Pilates Mat, Yoga, Funcional)
- Asignás precio mensual a cada una
- Los alumnos se vinculan a una actividad

7️⃣ GESTIÓN DE PROFESORES
- Registro de profesores
- Asignación a clases específicas
- Se muestra en el calendario quién da cada clase

📱 CARACTERÍSTICAS TÉCNICAS:
- Funciona en celular, tablet y computadora
- Todo en la nube (no se pierde nada)
- Sincronización automática entre dispositivos
- Interfaz simple e intuitiva
- Diseño responsive (se adapta a cualquier pantalla)

💰 INVERSIÓN:
- Instalación: $150.000 ARS (pago único)
- Mantenimiento: $20.000 ARS/mes
  O pago anual: $200.000 ARS/año (ahorrás $40.000)

La instalación incluye:
✅ Configuración completa del sistema
✅ Capacitación para tu equipo (2-3 horas)
✅ 1 mes de soporte incluido

El mantenimiento incluye:
✅ Hosting y base de datos
✅ Actualizaciones del sistema
✅ Soporte técnico
✅ Backup automático

¿Te gustaría agendar una demo gratuita para que lo veas funcionando? Podemos hacerlo por videollamada o presencial.
```
