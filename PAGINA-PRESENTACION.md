# 🎨 Página de Presentación para Vender el Sistema

## Idea: Crear una página de landing simple

Podés crear una página web simple (con Vercel o similar) que muestre:

### Secciones Sugeridas:

1. **Hero Section**
   - Título: "Gestioná tu estudio de Pilates, Yoga o Funcional desde un solo lugar"
   - Subtítulo: "Ahorrá tiempo, organizá mejor y crecé más"
   - Botón: "Agendar Demo Gratuita"
   - Imagen: Screenshot del dashboard

2. **Problema**
   - "¿Cansado de usar Excel y papel?"
   - Lista de problemas comunes

3. **Solución**
   - "SAVIA lo resuelve todo"
   - Características principales con íconos

4. **Características Detalladas**
   - Gestión de Alumnos
   - Control de Acceso
   - Calendario de Clases
   - Control de Pagos
   - Caja y Gastos
   - Asistencia de Alumnos
   - Todo desde el celular

5. **Demo/Video**
   - Video corto mostrando el sistema
   - O screenshots interactivos

6. **Precios**
   - Planes disponibles
   - Qué incluye cada plan

7. **Testimonios** (cuando tengas)
   - Frases de clientes satisfechos

8. **CTA Final**
   - "¿Listo para transformar tu estudio?"
   - Botón: "Empezá Ahora" o "Agendar Demo"

9. **Contacto**
   - Instagram
   - WhatsApp
   - Email

## Herramientas para Crear la Landing

1. **Vercel** (gratis) - Ya lo estás usando
2. **Carrd** (simple y rápido)
3. **Notion** (página pública)
4. **WordPress** (si querés algo más complejo)
